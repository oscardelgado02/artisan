## 15.11.2026
- Audited every pack and the `artisan-cli` skill against the actual CLI (each documented command, flag, help topic and file role re-checked against `artisan-uml-cli` source). Four doc-drift fixes, all verified against the CLI:
  - The scaffold packs and the workflow docs said stub notes were emitted as `// NOTE:` — the CLI switched to the unique `// ARTISAN-NOTE:` marker in 0.6.0 (that marker is what `scan` extracts back into diagram notes and what `scaffold` uses to manage its own comments). Corrected in all three `/artisan-scaffold` packs and `site/docs/workflow.md`.
  - The serve packs' kill command was `pkill -f "artisan.mjs serve"` — the server actually runs as `node <path>/artuml.mjs serve` (spawned by `lib/serve.mjs`), so the pattern never matched. Now `pkill -f "artuml.mjs serve"`.
  - The serve packs claimed the browser auto-open happens "when run interactively" — it opens whenever `ARTISAN_NO_BROWSER=1` is unset, including the packs' own backgrounded start. The background command in step 1 now sets `ARTISAN_NO_BROWSER=1` and the note states the rule.
  - The skill's command table was missing `scan [--lang csharp]` and `impl-diff [--src DIR]` — both added. The table is otherwise accurate end to end (all commands, all 13 help topics, the `app` alias, `--dir` on `add`/`edit node`, config keys, the `/api/status` shape, the network-on-first-install claim).
- Checked the installed copies for drift: the deployed `artisan-scaffold`/`artisan-implement` commands were the pre-0.6.0 generation (they told the agent to apply diffs by hand and delete code itself after a yes — exactly what the rewritten packs forbid). Reran the installer; all six commands plus the installed skill now byte-match the repo.

## 27.10.2026
- This repo now publishes to npm as **`artisan-agent`**: `npx artisan-agent install` installs the `artisan-uml-cli` and copies the six `/artisan-*` packs plus the `artisan-cli` skill into your agents' command folders. New installer `bin/artisan-agent.mjs` replaces `install.sh` — Node instead of bash, no PATH/rc-file editing (packs keep their own `npx artisan-uml-cli` fallback), flags `--all`, `--project`, `--tool opencode,claude,codex`, `--cli global|local|no` (auto: global first, then asks to install user-locally to `~/.local/share/pnpm`), and `list` / `uninstall` commands. Undetected tools are no longer skipped silently: the installer tells you to rerun with `--all`.
